Women's Fashion Store — UI/UX Design

A modern UI/UX design for a women's online fashion store, created in Figma.

Overview

This project focuses on creating a clean, elegant, and user-friendly shopping experience for an online women's fashion store.

Tools

- Figma

Designed Pages

- Home Page
- Product Listing
- Product Details
- Shopping Cart
- Checkout
